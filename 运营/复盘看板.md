- **阶段**：P0 启动前基线
- **本周期做了什么**：完成《赛博卜卦 · 推广与营收运营方案 v1.0》与本文档；现状梳理确认产品差异化（64 卦深解 + AI 结合所问之事解卦 + 铜钱仪式感）与短板（无埋点、无账号、无营收、AI 依赖外部密钥即成本点）。
- **指标快照**：暂无历史数据，WAC 基线待 P0 埋点上线后首周采集。

  2. 打赏/募集走 **爱发电**，规避个人经营性收款风险。
  3. 会员**只卖体验与便利（AI 不限次/更强模型/皮肤/存档），不卖预测准确性、不卖改运**，守住文化与娱乐边界。
  4. **免费用户 AI 解卦限次**是平衡 API 成本与会员转化的关键产品设计。
- **下周期 P0 动作**：
  - 埋点看板（1 周）
  - 卦象分享卡 + 邀请裂变（2 周）
  - 打赏链接 + 募集目标页（1 周）
  - 小红书/知乎账号装修 + 首发 6 条内容
- **风险**：AI API 成本是会员定价前必须算清的护栏；卜卦易踩"算命牟利"合规红线，文案守文化参考边界。
- **待确认**：个体户注册意愿（影响 P2 应用内支付时点）；Bonto 能否收支付回调。
