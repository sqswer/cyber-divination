## 1. 产品现状与定位（事实基础）

### 1.1 我们手里有什么（差异化卖点）
| 维度 | 现状 | 推广价值 |
|---|---|---|
| 内容深度 | **64 卦完整数据**：卦辞 + 精解 + 大象传 + 卦理；每爻含**爻辞 + 小象传 + 爻位分析（当位/得中/相应/承乘自动推导）+ 精解**；依朱熹《易学启蒙》断卦例法 | 「最严谨的一夜卜卦工具」可做成核心内容资产，区别于娱乐向算命小程序 |
| 零门槛 | **零安装、浏览器打开即玩**；Bonto 公网部署，发链接即开 | 朋友圈/群聊转发，对方点开就能算，转化极顺 |
| AI 解卦 | 接大模型（硅基流动 DeepSeek-R1 等），结合所问之事做**独立分析与建议**；思考过程已过滤，输出浅显分段 | 这是与所有"只给卦辞"工具的本质区别，是付费/口碑的核心支点 |
| 过程仪式感 | 三枚铜钱逐爻翻转 + 记分行 + 掷钱明细，古法概率（老阴/老阳各 12.5%） | "真卜卦"的体感，短视频好展示 |
| 白话总结 | 结果页先给一句话结论（本卦→变卦），再处境/走向/内情 | 降低《易》门槛，新手不劝退 |

### 1.2 当前短板（决定打法边界）
1. **无公网流量入口**：目前靠 Bonto 被动访问 + 熟人转发，没有主动获客。
2. **无埋点/无账号**：不知道谁在用、从哪来、问什么、复访多少——增长与营收决策盲飞。
3. **无营收**：纯公益，Bonto/大模型 API 成本无着落。
4. **AI 依赖外部密钥**：用户本地或 Bonto 配密钥才能用 AI 解卦；未配时只回提示词概览。这意味着**"AI 解卦"既是卖点也是成本点**——变现时要算清 API 账单。

### 1.3 一句话定位
> **「三枚铜钱真起卦、AI 结合你的问题给建议」的赛博卜卦网页版——比娱乐算命严谨，比古籍易读。**

### 1.4 与"狼人杀"项目的本质区别（避免套错打法）
| 维度 | 一夜狼人杀 | 赛博卜卦 |
|---|---|---|
| 使用场景 | 多人聚会/开黑，强社交 | **单人私密**，遇事犹豫时自己算 |
| 传播动机 | 约朋友一起玩（利他分享） | 自己用 + 偶尔转发"准不准"（利己/猎奇） |
| 频次 | 团建/聚会低频 | **高频情绪场景**（每天都有犹豫的事） |
| 付费心智 | 为"更好玩"付费 | 为"更准/更私密/更省心"付费、为"支持创作者"打赏 |
| 内容素材 | 角色图鉴、一局实况 | **卦象解读、运势话题、决策案例** |

> 结论：赛博卜卦是**"情绪 + 决策"型工具**，运营重心是**话题内容（SEO/搜索流量）+ 私密场景口碑**，而非社交裂变。

## 2. 目标与北极星指标

### 2.1 北极星指标（North Star）
**周活跃起卦数（Weekly Active Casts, WAC）** —— 比 DAU 更贴近"真实使用"，天然包含拉新（访问）+ 留存（复算）。

### 2.2 二级指标与分阶段目标
| 指标 | 定义 | P0（1 月后） | P1（3 月后） | P2（6 月后） |
|---|---|---|---|---|
| WAC（周活跃起卦） | 自然周内完成 ≥1 次起卦的去重会话数 | 300 | 1,500 | 6,000 |
| 新访客周增 | 每周新 UV | 200 | 1,000 | 4,000 |
| 起卦→AI 解卦转化 | 起卦后点「AI 解卦」的比例 | 25% | 40% | 50% |
| 次日/7 日留存 | 起过卦的用户回流比例 | — / 10% | 20% / 20% | 30% / 30% |
| 平均问题字数 | 用户填写"所问之事"的长度（衡量认真度） | — | 关注趋势 | 关注趋势 |
| 营收（月） | 打赏+募集+会员 | ¥200 | ¥1,500 | ¥8,000 |
| 付费率 | 月活中付费占比 | 0.3% | 1% | 2.5% |

> 目标值为内部基线假设，首月复盘后按真实数据校准，禁止拍脑袋硬套。

1. **每日/节气卦象**：结合节气、农历、热点事件，发"今日卦象 + 一句白话指引"（低成本、高复访）。

3. **起卦实况**：铜钱翻转 + 结果页截图，展示"真卜卦"仪式感与白话总结。
4. **易学小课**：卦辞/爻位术语科普（当位、得中、相应），建立专业信任。

## 4. 用户增长与留存优化（产品杠杆）

### 4.1 P0 —— 先把「盲飞」变「可见」（埋点，1 周内）
- server.js 在 `POST /api/divine`、AI 解卦调用时追加计数，写入 `data/stats.json`（新增目录，gitignore）。
- 记录：起卦次数、AI 解卦次数、来源 `ref`、是否配密钥。
- 交付只读 `/admin/stats` 接口，本地 `curl` 即可看。
- 隐私友好：不采个人信息，只记聚合计数。
- 负责人：你 ｜ 优先级 P0

### 4.2 P0 —— 卦象分享 + 邀请裂变（2 周内）
- 结果页新增「📤 分享我的卦象」：canvas 前端画分享卡（卦象三宫 + 一句话总结 + 站点链接 + 二维码），零后端。
- 分享链接带 `?ref=<sessionId>`，统计转化。
- 负责人：你 ｜ 优先级 P0

### 4.3 P1 —— 「每日一卦」回访钩子（1–2 月）
- 首页/分享卡引导「明天再来算一卦」，制造日回访理由（契合高频情绪场景）。
- 可做「本周卦象运势」轮播，轻量留存。
- 负责人：你 ｜ 优先级 P1

### 4.4 P1 —— 私密账号（为会员铺垫）
- 最简：`昵称 + localStorage uuid` 游客态；进阶邮箱。
- 存储 `data/users.json`，VIP 状态 `vipUntil`。
- 注意：卜卦是私密场景，**账号非必需**，先做"不打扰的轻账号"。
- 负责人：你 ｜ 优先级 P1

### 4.5 P2 —— 留存/氛围
- 卦象收集成就（64 卦集齐解锁彩蛋）。
- 节日主题（春节/端午卦象皮肤）。
- 负责人：你 ｜ 优先级 P2

## 5. 营收体系设计（打赏 / 募集 / 会员）

> 原则：**先轻后重、合规优先、不伤免费体验**。免费用户永远能完整起卦 + 看卦辞爻辞；付费是「更好/更私密/更支持」。

### 5.1 打赏（一次性，P0 立刻可做）
- **通道**：接入 **爱发电（afdian.com）** 个人赞助；同步放微信/支付宝收款码。
- **入口**：结果页/页脚「☕ 请开发者喝杯奶茶」→ 弹层展示收款码/爱发电链接 + 文案「服务器月租、大模型 API 账单，靠你续命」。
- **档位**：¥6 / ¥18 / ¥66 / 自定义。
- **合规**：明示「自愿赞助」，与卦象结果无关、非算命牟利、非赌博。
- 负责人：你 ｜ 优先级 P0（1 周内上线，先放链接）

### 5.2 募集（目标制众筹，P0–P1）
- **用途透明**：服务器月费、大模型 API 额度、新功能开发。
- **通道**：爱发电「目标」功能 + 站内「🔧 项目进度」页展示进度条（手动/API 同步）。
- **例子**：目标 A「服务器+API 续命」¥300/月；目标 B「卦象皮肤 ×3」¥600；目标 C「移动端 PWA」¥1,200。
- 负责人：你 ｜ 优先级 P0（与打赏同期）

### 5.3 会员（订阅制，P1–P2，需账号 + 算清 API 成本）
- **先决**：4.1 埋点 + 4.4 轻账号。
- **档位**：月卡 **¥9.9** ｜ 季卡 **¥25** ｜ 年卡 **¥88**。
- **核心矛盾——API 成本**：AI 解卦每调一次大模型都烧钱。会员权益设计必须围绕"值回票价"且**可控成本**：
  | 权益 | 免费 | 会员 |
  |---|---|---|
  | 起卦 + 卦辞爻辞 + 白话总结 | ✅ | ✅ |
  | AI 解卦 | ✅（**限次**，如每日 3 次） | ✅（**不限次 / 更高额度**） |
  | AI 模型档位 | 标准模型 | **可选更强模型 / 更长分析** |
  | 卦象皮肤/头像框 | 默认 | 限定 |
  | 历史卦象存档 | — | ✅（我的卦象本） |
  | 去广告承诺 | 永不广告 | 永不广告 |
- **限次是关键产品设计**：免费用户给"每日 N 次 AI 解卦"既能控成本，又能自然引导会员转化（"今天额度用完了？开通会员无限算"）。
- **支付通道（合规）**：
  - 个人阶段：**爱发电月捐** 模拟订阅，最稳，无需商户号。
  - 规模化后：注册**个体工商户 + 微信支付商户号**，服务端 `/api/pay/notify` 验签开通会员。Bonto 有公网域名可收回调，但需先验证。
- **红线**：AI 解卦**绝不承诺预测结果准确性**，只做"参考与分析"；不卖"改运/消灾"等迷信服务；明示娱乐文化属性。
- 负责人：你 ｜ 优先级 P1（账号+成本模型清晰后做）

### 5.4 营收落地顺序
```
P0：打赏链接 + 募集目标页（1 周，零成本，先有现金流）
  ↓
P1：轻账号 + 会员月捐（爱发电）+ 免费用户 AI 限次（1–2 月）
  ↓
P2：应用内支付 + 限定皮肤 + 历史存档（营收过阈值后）
```

### 5.5 成本护栏（重要）
- 上线会员/限次前，必须在 server.js 统计**每个会话的 AI 调用次数与 token 消耗**，算出单用户月 API 成本。
- 会员定价必须覆盖"重度用户"的 API 账单（¥9.9/月 至少要覆盖数十次深度解卦的 token 成本，否则亏本）。
- Bonto 部署的 API key 在服务器侧，用户免配置即可用 AI——这是体验优势，但**成本全压在 owner 身上**，必须用"免费限次 + 会员不限"平衡。

## 6. 技术实现要点（贴着现有零依赖栈）

> 现状：Node 内置 http + SSE + 内存/文件存储，无数据库。改造尽量小步、可回滚。

### 6.1 埋点（P0）
- `server.js` 在 `/api/divine`、`/api/ai/interpret` 追加计数，写 `data/stats.json`。
- 只读 `/admin/stats` 返回 JSON。

### 6.2 分享卡（P0）
- 前端 canvas 画卦象三宫 + 总结 + 站点二维码，下载/复制。

### 6.3 轻账号 + 限次（P1）
- `data/users.json` 存游客/邮箱账号；`vipUntil` + `aiUsedToday` 字段。
- 免费用户每日 AI 解卦次数上限（如 3），超限提示开通会员。

### 6.4 支付与会员开通（P2）
- 爱发电月捐：手动/API 拉订单匹配写 `vipUntil`。
- 微信支付：`/api/pay/notify` 收回调 → 校验 → 写 `vipUntil`。

### 6.5 原则
- 不引入重依赖；新功能走独立路由 `/api/pay`、`/admin/*`。
- 每次改动仍走「本地改 → git push → Bonto 拉取」。

## 8. 复盘机制

- **节奏**：双周小复盘，月度大复盘。
- **模板**：见同目录 `复盘看板.md`。
- **指标口径**：严格按第 2.2 节，避免口径漂移。
- **决策规则**：
  - 某渠道连续 2 个双周新访客 < 目标 50% → 砍投入或换形式。
  - AI 解卦转化 < 20% → 先查入口曝光与文案，不急着加权益。
  - 打赏月转化 < 0.3% → 检查入口与文案。
- **红线**：不卖预测准确性、不卖改运消灾、不接赌博/抽成；用户隐私只采聚合计数；AI 解卦明示娱乐文化属性。

## 9. 风险与待确认
1. **API 成本**：AI 解卦是核心卖点也是成本点，会员定价前必须算清单用户账单（见 5.5）。
2. **合规**：卜卦工具易踩"算命牟利"红线，文案务必守"文化参考/娱乐"边界，不承诺准确性、不卖改运。
3. **支付合规**：正式会员建议个体户 + 微信支付商户，个人收款做经营性有风险（已用爱发电过渡）。
4. **Bonto 限制**：确认能否稳定收支付回调；不能则支付走爱发电外部完成。
5. **账号体系**是会员前必补课，但卜卦私密场景需"轻账号不打扰"。
